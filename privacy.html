隐私政策

扩展名称：接口代理&WS抓包导出工具（api-proxy-ws-tool）
生效日期：2026-11-12

一、数据处理声明

  1. 不收集任何个人数据。本扩展不收集、不上传、不共享、不出售浏览历史、请求内容、响应内容或 WebSocket 报文。
  2. 代理规则只存在本机。规则保存在 chrome.storage.local，不上传、不云同步；卸载扩展即删除。规则中的请求头（可能含访问令牌）同样只存本机明文、不上传；导出规则时默认脱敏。
  3. WebSocket 帧只存在页面内存。帧数据由注入到被检查页面的脚本保存在该页面的内存中，刷新/关闭页面即释放；只有用户点击"导出"时才会生成本地文件，文件去向由用户自行决定。
  4. 权限按需申请。安装时不申请任何网站访问权限；只有在用户新增规则并点击【授权此域名】后，才会针对该域名弹出系统授权框；授权可随时撤销。
  5. 无分析 SDK、无远程配置。扩展不包含统计、埋点、崩溃上报、A/B 或远程开关；所有代码随安装包分发，运行时不下载、不执行任何远程代码。
  6. 不读取无关数据。授权范围只来自用户创建的规则域名，不读取当前标签页 URL、不写入存储、不打印日志、不外发。
  7. 联系方式：仓库 Issue。
  8. 变更：隐私政策更新会在商店描述与仓库同时标注日期。

Privacy Policy (English)

This extension collects no user data. Redirect rules and user-configured request headers are stored locally via chrome.storage.local and are never uploaded; exported rule files redact sensitive header values by default. WebSocket frames are kept in the inspected page's memory and are only written to a local file when the user explicitly exports them. No analytics, telemetry, remote configuration, or remotely hosted code is used. Host permissions are optional and requested per domain only after an explicit user action; they can be revoked at any time in the browser's extension settings.
